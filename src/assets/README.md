# Assets Directory

This directory holds static assets for the Gradient website.

## Structure

```
assets/
├── images/
│   ├── logo/        — Gradient logo assets
│   ├── events/      — Event photography
│   ├── boards/      — Board member photography
│   ├── projects/    — Project imagery, screenshots, diagrams
│   └── general/     — Other brand/general imagery
└── fonts/           — Local font files (if needed in future)
```

## Image Guidelines

Per the Gradient specification:
- The imagery system must support raw/unpredictable real-world images.
- Do not assume every image will be 16:9, professionally shot, equally lit, or similarly composed.
- Never stretch or distort images.
- Use intelligent cropping by default.
- Missing imagery must not be fabricated; layouts adapt.
- Meaningful imagery needs appropriate alternative text.

Actual image assets will be introduced in later phases.
